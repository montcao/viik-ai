# Contributing

viik's source code is private, so this repository doesn't take code contributions. The most useful things you can contribute are clear bug reports and well-explained feature requests.

## Writing a good issue

1. **Search first.** Someone may have already reported it. If so, add a 👍 reaction instead of a "+1" comment, and add any new details you have.
2. **One issue per problem.** Separate issues are easier to track and close.
3. **Use the templates.** They ask for the details we need to reproduce the problem.
4. **Be specific.** Include which chat assistant you used, what you asked viik to do, what you expected, and what actually happened. Approximate date and time help us find the logs.
5. **Keep it anonymous.** Never include your resume or personal details. Describe the problem in general terms instead, for example "a resume with two columns" or "a date written as 'Spring 2024'".
